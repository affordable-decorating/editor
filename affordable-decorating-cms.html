Site editor

Edit the site with forms

This page edits the data files for the Affordable Decorating site. It does not need a server and is not part of the site; keep it outside the folder you upload.

From any device: choose Open from GitHub, enter your repository and an access token, and every save is committed straight to the hosted site.

Or from a folder on this computer: choose Open site folder and select the site folder (the one that contains index.html and data). Your browser will ask permission to edit it. Saving writes straight to the data files, and images and downloads you attach are copied into images/ and files/ for you.

Without GitHub: this browser cannot edit folders directly, so choose Open data files and select items.json, departments.json and (if present) collections.json, pages.json and intranet.json from the site's data folder. After saving, use Download changed files and replace the originals. Attached images and downloads have to be copied into the site folder by hand; type their paths into the form. For the full experience use Chrome or Edge.

    Open from GitHub

    Edit the site where it is hosted. Each save becomes a commit in the repository, and GitHub Pages republishes the site a minute or two later. This works on any device, including a phone.

    Create one at github.com/settings/personal-access-tokens/new: Repository access, Only select repositories, choose this repository; Repository permissions, Contents: Read and write; nothing else. Set an expiry. Treat it like a password: anyone who has it can change the repository.
    Stored in this browser only. Leave it unticked on a shared or borrowed computer.
